# Runbooks

Step-by-step operating instructions, **written for someone who did not build the thing.**

The test for every runbook here: could a teammate who has never opened the source follow it, alone, at 3am, correctly?

Usual set:

- **How to stop it.** The most important page in the repo. One step. No permission required.
- **How to start it again.** Deliberately harder than stopping.
- **Key or credential rotation.** Written *and tested by someone other than its author.*
- **Incident note** — [`incident-template.md`](incident-template.md).

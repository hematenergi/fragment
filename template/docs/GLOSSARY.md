# Glossary

For teammates who are not engineers. Open when you need it; nothing to memorize.

**If a term shows up in chat and is not here, ask for it to be added** — you are almost certainly not the only one who was unsure.

## Process terms

| Term | What it means |
|---|---|
| **Fragment** | One self-contained piece of work. See `HOW-WE-WORK.md` |
| **Repo** | The project folder plus its whole change history |
| **CI** | A robot that checks the rules on every change. If it goes red, something broke a rule |
| **PR** | A proposed change, packaged for someone else to review before it lands |
| **Runbook** | Step-by-step instructions to operate something, written for someone who did not build it |
| **Superseded** | Replaced by something newer. The old document stays, labeled, so the trail survives |
| **Frontmatter** | The small block at the top of a document saying who owns it and when it was last checked |

## Three things that matter most for you

### 1. <THE MOST IMPORTANT THING SOMEONE CAN DO — usually: how to stop it>

<Point at the runbook. Make it one step. If stopping requires understanding the code, it is not a stop button.>

### 2. Numbers are only real if they come out of the system

If you hear a number in chat that is not in a report the system produced, treat it as unverified — not because anyone is lying, but because numbers computed by hand in systems like this are almost always wrong in the same direction.

### 3. If something looks off, say so — even if you are not sure

"This looks weird to me" is a useful contribution. The most expensive failures are the quiet ones: no error, no alarm, just days that disappear before anyone notices.

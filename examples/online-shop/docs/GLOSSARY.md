# Glossary

For anyone who does not read code. Open it when you need it; nothing to
memorise.

**If a word turns up in chat and is not here, ask for it to be added** — you are
almost certainly not the only one who was unsure.

## Words about how we work

| Word | What it means |
|---|---|
| **Fragment** | One self-contained piece of work. See [`HOW-WE-WORK.md`](HOW-WE-WORK.md) |
| **Session** | One sitting with an AI agent. It starts with no memory of the last one |
| **Repo** | The project folder, plus every change ever made to it |
| **Deploy** | Putting a new version of the shop online |
| **CI** | A robot that checks our rules on every change. Red means a rule broke |
| **Runbook** | Step-by-step instructions for doing something to the live shop, written for whoever is holding the phone at the time |

## Words about the shop

| Word | What it means |
|---|---|
| **Catalogue** | The list of things we sell |
| **Cart** | What a customer has picked but not yet paid for |
| **Checkout** | The paying part. Not finished yet |
| **Test key / live key** | Two passwords for the payment company. The test one moves pretend money, the live one moves real money. Mixing them up cost us once |
| **Dashboard** | The payment company's screen showing real orders. The only numbers we trust |

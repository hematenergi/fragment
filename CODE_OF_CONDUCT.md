# Code of conduct

Be decent. Assume the other person is trying.

This project is about making disagreements resolvable by evidence rather than by
who spoke last, so the standard here is simple: **argue about the claim, not the
person.** "This check is wrong because X" is always welcome, including when
addressed to a maintainer. "You clearly don't understand X" is not.

Specifically, in issues, pull requests and reviews:

- Bring the reproduction. A bug report with the failing command in it is worth
  ten without.
- Being right is not a license to be unpleasant about it.
- Being a maintainer is not a license to dismiss without a reason.
- No harassment, personal attacks, or discriminatory language. Ever, anywhere,
  including in commit messages and code comments.

Report anything that crosses those lines by opening an issue, or privately to
the address in [`SECURITY.md`](SECURITY.md) if it should not be public.
Maintainers will respond, and may edit, hide, or remove contributions, or block
accounts.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/),
kept short so it is actually read.

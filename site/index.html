The continuity layer of your AI coding harness.

Harness engineering chooses the context an agent sees, the rules it follows, and the feedback that closes the loop. Fragment handles the part that usually disappears between sessions. It does not run the model; it gives whoever arrives next the same durable story.

The last five minutes of work become the first five minutes of the next session.

Receipts, not promises.

Extracted from a private repo: two people, two operating systems, two different AI agents, 25 commits in 18 hours.

Receipt What happened
74 minutes from CI install to its first real catch
3 violations from one ordinary file rename, all caught
7 of 7 new-contributor commits carried the same handoff shape
both directions the verification rule corrected a colleague and its own author

What this does not prove

Concurrency above two people is untested. Fragment verifies continuity, not code correctness.
